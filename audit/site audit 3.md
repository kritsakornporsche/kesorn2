### 📌 รายการที่ต้องแก้ (ส่งเพื่อนชุดเดียว)

**🔴 ต้องแก้ก่อนเริ่มทดสอบจริง**
1. **ออกบิลจากเลขมิเตอร์ (ข้อ D3) — ต้องยืนยัน** ตอนตรวจเจ้าของหอ (13:55) เลือกห้องในฟอร์ม "ออกบิลรายห้อง" แล้วช่องค่าน้ำ/ค่าไฟเป็น 0 แต่ตอนตรวจลูกหอพบบิลใบหนึ่งมีค่าไฟ 350 บาท (= 50 หน่วย × 7 ตรงกับมิเตอร์ห้อง 5) แสดงว่าอาจเพิ่งแก้ แต่บิลนั้นบันทึก "หน่วยไฟ = 0" และค่าเช่า 3,500 ทั้งที่ห้อง 5 ราคา 2,800 → ให้เพื่อนยืนยันว่า ฟอร์มออกบิลรายห้องและปุ่มออกบิลทั้งหอ คำนวณ ค่าไฟ = (เลขนี้ − เลขก่อน) × 7, ค่าน้ำ = 100, ค่าเช่าตามราคาห้อง และบันทึกจำนวนหน่วยลงบิลด้วย
2. **ปุ่ม "🧪 DEV TESTING — ยืนยันการย้ายออก (TEST RESET)" ยังอยู่ในหน้าหลักลูกหอ** (รีเซ็ตห้องและบทบาทกลับเป็น GUEST) — ปุ่ม GLOBAL RESET หายแล้ว แต่ปุ่มนี้ต้องลบด้วย
3. **สลับบทบาทแล้วขึ้น "คุณไม่มีสิทธิ์เข้าถึงหน้านี้ (เฉพาะผู้ดูแลหอพัก)"** ต้องรีโหลดหน้าก่อนจึงเข้าได้ (ผู้ใช้พบตอนกดเข้าสู่ระบบด่วนเปลี่ยนบทบาท)
4. **ล้างข้อมูลทดสอบเดิมก่อนเริ่มทดสอบจริง + กันบิลซ้ำ** — ลูกหอห้อง 5 มีบิล 6 ใบ (รอบ ต.ค. 2569 ซ้ำกัน 4 ใบ ยอดค้าง ฿12,350) และงานแจ้งซ่อม "เทสระบบ"/"ทดสอบแจ้งซ่อม" ค้างอยู่ → ล้างให้ว่าง; ระบบยอมให้ออกบิลรอบเดียวกันให้ผู้เช่าคนเดียวซ้ำได้ ควรกันไว้; รูปแบบรอบบิลปนกัน ("ตุลาคม 2569" / "2026-10")
12. **งานทำความสะอาดของแม่บ้านสร้างไม่ได้ (ใช้งานไม่ได้ตั้งแต่ต้นทาง)** — ลูกหอไม่มีเมนูแจ้งทำความสะอาด, หน้าแม่บ้านไม่มีแถบเมนูเหมือนบทบาทอื่น และ (จากโค้ดบน GitHub) ไม่มีส่วนไหนของระบบสร้างงานทำความสะอาดเลย แม่บ้านจึงดู/อัปเดตงานได้อย่างเดียวแต่ไม่มีงานเข้ามา → ถามเพื่อนว่าทำทันก่อนหยุดแก้ระบบไหม: (ก) เจ้าของหอมอบหมายงานทำความสะอาดห้องให้แม่บ้าน และ/หรือ ลูกหอแจ้งขอทำความสะอาด, (ข) แม่บ้านรับงาน → อัปเดตสถานะ → ปิดงาน, (ค) เพิ่มแถบเมนูหน้าแม่บ้าน — ถ้าไม่ทัน ผู้วิจัยต้องแก้เล่ม (ดูหัวข้อกระทบเล่ม)

**🟡 ข้อมูลต้องตรงกันและเป็นของจริง**
5. **อัตราค่าน้ำค่าไฟขัดกันเอง (แม้ในหน้าเดียวกัน)** — หน้ารายละเอียดห้อง ส่วน "อัตราค่าน้ำ/ค่าไฟ" เขียน ค่าน้ำ ฿100 ค่าไฟ ฿7 (ตรงกับค่าตั้งค่าและบิลจริงในเล่ม) แต่ส่วน "สรุปค่าใช้จ่ายการจอง" และหน้าแรกเขียน "ฟรีค่าน้ำ, ค่าไฟ ฿6/ยูนิต" → ถามอัตราจริงแล้วแก้ทุกจุดให้ตรงกัน
6. **เงินจอง/เงินประกัน** — ระบบเก็บ "ค่าจอง 1,000 บาทวันนี้ + เงินประกัน 2,000 บาทวันย้ายเข้า" แต่เล่ม (TC-19) เขียน "ชำระเงินประกันสัญญาเช่า (1 เดือน) ตอนจองผ่าน QR" → ยืนยันว่าแบบในระบบคือของจริง (ถ้าใช่ ผู้วิจัยแก้เล่ม)
7. **ราคาห้อง** — ห้องในระบบราคา 2,800 และ 3,400 บาท แต่หน้าแรกเขียน "2,800 - 3,100 / ด."
