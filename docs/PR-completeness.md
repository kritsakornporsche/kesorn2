## สรุป
ทำให้ระบบหอใช้งานได้ครบตั้งแต่จองจนย้ายออก โดยย้ายกติกาเงินทั้งหมดไปไว้ที่ server (`lib/*.ts`) และปิดช่องที่หน้าเว็บส่งยอดเงินเองได้

- **ความปลอดภัย (1–3):** ตัดรหัสผ่านสากล/ทางลัด role · ตรวจสิทธิ์จาก DB ทุก API · บทบาท **manager** · ลบหน้าเก่าและหน้าทดสอบ (`/admin`, `/platform`, `/researcher` ฯลฯ)
- **บิลและเงิน (4–8):** คิดยอดที่ server · บิลรายเดือน ร่าง → ส่ง → ชำระ (ล็อกเมื่อจ่าย, ยกเลิกได้โดย owner + เหตุผล) · รับเงินทางเดียว (สลิปยอดตรง / เงินสด / บางส่วน) + ใบเสร็จ · ค่าปรับต่อวันไม่มีเพดาน · เงินประกันเป็นหนี้สิน
- **สัญญาและการจอง (9–11):** service สัญญาเดียว · จองแบบอนุมัติแล้วจ่ายภายใน 10 นาที (08:00–20:00) · บิลเข้าอยู่ + สัญญากระดาษที่เซ็น → สัญญามีผล · เพดาน สคบ. (ประกัน + ค่าเช่าเดือนแรก ≤ 3 เท่า) · ตรวจห้องก่อนเข้าอยู่
- **ย้ายออก (12):** แจ้งย้ายออก → คืนห้อง → ปิดบัญชีเงินประกันตาม สคบ. ข้อ 13 → คืนเงินภายใน 7/14 วัน
- **งานซ่อม (13):** บอร์ดเดียว ผู้เช่าแจ้ง → มอบ/รับงาน → ปิดงาน → owner ตัดสินค่าใช้จ่าย
- **มิเตอร์ (14):** จดที่ server รอบละครั้ง (วนรอบ/เปลี่ยนเครื่อง) → บิลรายเดือนรอบละใบ
- **อัตราและแจ้งเตือน (15):** หน้าตั้งค่าเดียว + ประวัติ · แจ้งเตือนตามเวลา (จดมิเตอร์, ใกล้/ถึงกำหนด, ค้าง 15 วัน, บิลเข้าอยู่, จองหมดเวลา) ผ่านการเปิดหน้าหรือ cron
