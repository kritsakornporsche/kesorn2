## A. ข้อความบนหน้าเว็บไม่ตรงกับเล่ม/สัญญา

### A1 กล่องกฎหอบนหน้าแรก `/`
| ที่แสดงอยู่ | ควรเป็น |
|---|---|
| "ค่าน้ำประปา: เหมาจ่าย 100 บาท/เดือน" | "ค่าน้ำประปา 100 บาท/คน/เดือน" |
| "ค่าไฟหน่วยละ **7** บาท" | "ค่าไฟหน่วยละ **8** บาท" |
| "จองเพียง 1,000 บาท • **เงินประกัน 2,000** บาท" | "ค่าจอง 1,000 บาท • ค่ามัดจำรวม 3,000 บาท (ส่วนที่เหลือ 2,000 บาท ชำระวันเข้าพัก)" |
| "ชำระเงินมัดจำออนไลน์ได้ทันที" | "ชำระค่าจองห้องออนไลน์ได้ทันที" |

- [ ] ส่วนอื่นของหน้าแรก (การ์ดห้อง คำอธิบายหอ) ถูกต้องแล้ว เหลือเฉพาะกล่องนี้

### A2 หน้าผู้ดูแลประจำหอพัก `/keeper/technician`, `/keeper/maid`
- [ ] มีป้าย **"Multi-Dormitory"** เมนู **"สลับหอพัก"** และตัวเลือก "ทุกหอพัก (1)"
  - เล่มเขียนว่า Multi-Dorm อยู่นอกขอบเขต ควรซ่อน หรืออย่างน้อยไม่ให้ติดในภาพหน้าจอที่ใส่เล่ม

### A3 หน้าสัญญาเช่า `/owner/contracts`
- [ ] แท็บ "คำร้องย้ายออก & คืน**เงินประกัน**" → เปลี่ยนเป็น "คืน**ค่ามัดจำ**" ให้ตรงกับหัวข้อหน้า

### A4 บิลค่าจองห้อง `/owner/billing`
- [ ] บิลค่าจองห้อง 5 ยอดสุทธิ ฿1,000 ถูกแล้ว แต่ช่องยอดแยกย่อยแสดง "ค่าห้อง: **฿7,000**" ควรแสดง "ค่าจอง: ฿1,000"
- [ ] บิลรายเดือนแสดงค่าน้ำเป็น "น้ำ: 1.00 **น.** (฿100)" ดูเหมือนหน่วยมิเตอร์ ควรแสดง "ค่าน้ำ (เหมาจ่าย): ฿100"

### A5 เลขเวอร์ชัน
- [ ] หน้าเจ้าของหอแสดง "SmartDom Owner **v2.6.1**" แต่หน้าเว็บเคยแสดง v2.7.0-b252 ควรให้ตรงกัน (ใช้อ้างในเล่มว่าทดสอบเวอร์ชันไหน)

### A6 หน้าจดมิเตอร์ `/owner/meters` (พบตอนทดสอบ TC-08)
- [ ] ป้ายยังแสดง "ไฟฟ้า (หน่วยละ **7** บาท)" 3 จุด (หัวหน้า, การ์ดหน่วยไฟฟ้ารวม, ตัวกรองประเภทมิเตอร์) แต่ตั้งค่าเป็น 8 แล้ว
- [ ] "ค่าน้ำเหมาจ่าย 100 บาท/เดือน" → "100 บาท/คน/เดือน" (ในระบบคิดต่อห้องตามข้อจำกัดข้อ 5 ในเล่ม ใช้ได้ แต่ควรให้ข้อความตรงกัน)
- [ ] เลขเวอร์ชันมุมซ้ายล่างยังเป็น **v2.7.0-b252 (c69114c)** เหมือนก่อนแก้ ควรเปลี่ยนเลขเมื่อ deploy ใหม่ เพื่ออ้างในเล่มว่าทดสอบเวอร์ชันไหน
