### 🔴 ความปลอดภัย/เสี่ยงข้อมูลหาย
1. **ปุ่ม "🧪 DEV TESTING — GLOBAL RESET (ล้างประวัติ & ทำให้ห้องว่างทั้งหมด)"** แสดงในหน้าหลักลูกหอ (/tenant) และ Guest ก็เปิดหน้านี้ได้
2. **ข้ามสิทธิ์ได้ (ขัดกับ SEC-02 ในเล่ม)**: ลูกหอและ Guest เปิดหน้าเจ้าของหอ (/owner, /owner/tenants, /owner/billing) ได้ และ API /api/tenants?dormId=1 กับ /api/owner/stats ตอบ 200 ให้ลูกหอ/Guest; แม่บ้านก็เปิดหน้าเจ้าของหอได้
3. **ไม่ล็อกอินก็เปิดหน้าเจ้าของหอได้ (ขัดกับ SEC-01)**: /owner ไม่ redirect; /api/owner/stats ตอบโดยไม่ต้องล็อกอิน

### 🟠 API ตอบ 500
ยืนยันได้ 1 ข้อความ: `Table 'kesorn_db.keeper_dormitories' doesn't exist` (ข้ออื่นขึ้นแค่ Internal Server Error)
- เจ้าของหอ: จดมิเตอร์ (/api/owner/meters), สัญญาเช่า, แจ้งซ่อม, บัญชีรายรับ-จ่าย, กฎระเบียบ, ทีมผู้ดูแล, คำร้องคืนมัดจำ
- แม่บ้าน/ช่าง: ทุกหน้า — จอแสดง "0 งาน" แต่จริงๆ คือ error
- ลูกหอ: สัญญา (/api/tenant/me), ประกาศข่าว (หน้า crash), กฎระเบียบ, คำร้องคืนมัดจำ
- ทุกบทบาท: แชท (/api/chat/conversations), โปรไฟล์ (/api/user/profile)
- แอดมิน: role = owner → /platform, /platform/status, /platform/tenants เด้งไป signin; /platform/dormitories, /platform/accounting, /admin/news API 500
